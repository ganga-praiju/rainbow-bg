## 1. Rainbow Background

### Description
The **Rainbow Background** project changes the background color of the webpage to a sequence of rainbow colors when a button is clicked.

### Files
- `colour.html`

### How It Works
- A button is displayed in the center of the page.
- When the button is clicked, the background color cycles through the colors of the rainbow (`red`, `orange`, `yellow`, `green`, `blue`, `indigo`, `violet`).

### Usage
1. Open `colour.html` in a browser.
2. Click the button to see the background color change.
